# Commit Hike

*[English](README.md)*

Кожен твій коміт просуває тебе туристичною стежкою просто в IDE.

## Можливості

- **Справжні маршрути.** Пройди Чорногірський хребет від Заросляка через Говерлу до Попа Івана або коротку демо-стежку. У кожного маршруту свої точки, історія й досягнення.
- **Чесна відстань.** Метри ростуть разом із розміром коміту, але повільно: маленькі коміти теж рахуються, а великими «накрутити» не вийде. Lock-файли, згенерований код, зміни лише в пробілах і чужі коміти не рахуються.
- **Твоя мова.** Тексти маршрутів перекладені; ядро бере мову IDE, а якщо перекладу немає, показує англійську.
- **Приватність за замовчуванням.** У твої репозиторії нічого не записується, і нічого не залишає твій комп'ютер. Не зберігаються ні код, ні повідомлення комітів, ні назви файлів чи репозиторіїв.

## Підтримувані IDE

| IDE | Статус |
|---|---|
| IDE JetBrains 2024.3+ (PyCharm, IntelliJ IDEA, GoLand, WebStorm…) | у розробці |
| VS Code 1.85+ | у розробці |

## Структура репозиторію

```
core/            рушій на Go: підрахунок, збереження, маршрути, досягнення, переклади, малювання
  content/routes/  вбудовані маршрути (route.json + locales/*.json)
ui/panel/        панель зі стежкою, спільна для всіх плагінів
plugins/vscode/  розширення для VS Code (TypeScript)
plugins/jetbrains/  плагін для IDE JetBrains (Kotlin)
docs/            архітектура, протокол, як додати маршрут
```

## Розробка

Потрібні Go, Node.js 22, JDK 21 і [Task](https://taskfile.dev) (`sudo snap install task --classic`).

```bash
task setup               # перевірити інструменти, встановити лінтери, завантажити залежності
task                     # список усіх команд
task test                # усі тести: ядро, маршрути, VS Code, JetBrains
task lint                # golangci-lint, ESLint + tsc, ktlint
task check               # усе, що перевіряє CI; запускай перед push

task core:demo REPO=~/projects/my-app    # спробувати ядро на справжньому репозиторії (тестові дані)
task core:run -- status --lang uk         # викликати будь-яку команду ядра

task jetbrains:install   # зібрати й встановити плагін у PyCharm, потім перезапустити його
task jetbrains:run-pycharm   # або запустити PyCharm з плагіном в окремому профілі
task vscode:install      # зібрати й встановити розширення для VS Code

task deps:outdated       # що можна оновити
task deps:update         # оновити залежності й перезапустити всі перевірки
```

## Як додати маршрут або переклад

Маршрут — це тека з `route.json` і файлом на кожну мову. Код змінювати не потрібно, див. [docs/routes.md](docs/routes.md). Якщо переклад неповний, тести падають, тож відсутній рядок ніколи не дійде до користувачів.

## Як це працює

Плагіни для IDE тонкі: вони помічають коміти й малюють результат. Уся логіка живе в одному невеликому бінарнику на Go, який плагіни викликають і який відповідає версіонованим JSON. Докладніше: [docs/architecture.md](docs/architecture.md), [docs/protocol.md](docs/protocol.md).

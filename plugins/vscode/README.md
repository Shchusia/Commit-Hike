# Commit Hike

Every commit you make moves you along a hiking trail.

- **Nothing touches your projects.** No git hooks, no files in your repository. Commit Hike only reads your git history.
- **Everything stays on this computer.** No accounts, no network requests.
- **Real work counts.** Lock files, generated code, whitespace-only changes and other people's commits don't.

Open the Commit Hike view in the activity bar to see your trail. The status bar shows how far you've walked.

## Commands
- **Commit Hike: Set Up** — choose which projects count and where your journey starts.
- **Commit Hike: Choose Trail for All Projects / for This Project**
- **Commit Hike: Count This Project / Stop Counting This Project** — when you count only chosen projects.
- **Commit Hike: Recount This Project from Git History** — rebuilds this project's progress if anything looks off.
